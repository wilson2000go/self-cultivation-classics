## 如何收听

- **方式一**：直接在本仓库 `books/<书名>/audio/` 目录中点击音频文件，在 GitHub 网页即可在线播放 / 下载。
- **方式二**：克隆整个仓库到本地，离线收听：

  ```bash
  git clone https://github.com/wilson2000go/self-cultivation-classics.git
  ```

## 项目结构

```
self-cultivation-classics/
├── README.md                  # 本文件：项目总览与收听方式
└── books/                     # 每本书一个子目录
    ├── _template/             # 【模板】新增书籍时复制此目录
    │   ├── README.md
    │   ├── manifest.json
    │   └── audio/             # 放置该书的音频
    └── 楞严大义今释/           # 第一本书
        ├── README.md          # 书籍信息与章节清单
        ├── manifest.json      # 机器可读元数据（书名 / 作者 / 章节 / 音频 / 时长）
        └── audio/             # 音频文件（每章一段）
            ├── 00_导言.mp3
            ├── 01_心性本体论.mp3
            └── ……（07）
```

## 如何新增一本书（框架约定）

1. 复制 `books/_template/` 为 `books/<书名>/`（目录名用中文或拼音均可）。
2. 把该书每章（或每段）的音频放入 `books/<书名>/audio/`，命名建议 `01_xxx.mp3`、`02_xxx.mp3`……；全书导言用 `00_导言.mp3`。
3. 编辑 `manifest.json`：填写 `book_id`、书名、作者、音色，以及 `tracks` 数组（每首的编号、标题、文件名、时长秒数）。
4. 更新本书的 `README.md` 章节清单，并在本仓库根 `README.md` 的「收录书目」中追加一行。
5. 提交并推送。

> **统一约定**：每章 / 每段对应**一段**音频；所有音频建议统一裁剪片头静音（本项目统一删去前 6 秒），并转码为 **MP3（128kbps）** 以控制仓库体积。

## 音频说明

- **音色**：统一使用 **子言（深沉·磁性入耳·男声）** 单人播讲。
- **内容**：取自原著的白话讲解 / 串讲部分，忠实原文、逐段讲全讲透。
- **处理**：每段音频已删除片头前 6 秒，并转码为 MP3（128kbps）。
